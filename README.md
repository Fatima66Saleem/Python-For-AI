# Python for AI

This repository contains Python-based Artificial Intelligence lab work, assignments, and notebook files for the AI subject. It is designed for students who are learning how to use Python for AI concepts, problem solving, and practical implementation.

## Repository Purpose

The goal of this repository is to help students:

- Practice Python programming for AI tasks
- Solve AI assignments and lab exercises
- Work with Jupyter Notebooks
- Learn data handling, visualization, and basic AI/ML concepts
