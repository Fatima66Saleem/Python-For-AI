# Python for AI

## Repository Purpose

The goal of this repository is to help students:

- Practice Python programming for AI tasks
- Solve AI assignments and lab exercises
- Work with Jupyter Notebooks
- Learn data handling, visualization, and basic AI/ML concepts

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/Fatima66Saleem/Python-For-AI.git
```

2. Open the project folder:

```bash
cd Python-For-AI
```

3. Create a virtual environment (optional but recommended):

```bash
python -m venv venv
```

4. Activate the environment:

Windows:

```bash
venv\Scripts\activate
```

Linux/macOS:

```bash
source venv/bin/activate
```

5. Install dependencies:

```bash
pip install jupyter numpy pandas matplotlib seaborn scikit-learn
```

6. Start Jupyter Notebook:

```bash
jupyter notebook
```
